XII.3

Notation and its colours

Every symbol on this site has exactly one meaning, and is coloured by the kind of quantity it is.

The colour of a symbol tells you what kind of thing it is before you read it. Hover any symbol on any page for its reminder.

lKV-layer index — Which KV layer, from 0 to NL​−1 (layer_id).
\vl		III.1
celement index — Which element position inside a vector, from 0 to d−1 (elem_id); one fixed c across many vectors is a furrow.
\vc		II.13

\vrho		IV.8

\vfD		VI.3

\vRsq		II.12

\veps		II.9

\veta		per stepVII.10

\vshare		XI.4

\vphat		II.8
