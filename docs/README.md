# Docs catalog

Short, single-purpose docs. Load the one your task needs; each links onward. `AGENTS.md` at the repo root
is the entry point for agents; `README.md` is the public face of the repository.

## project/ — what kv-blockdiff is and what we know

| doc | read it when |
|---|---|
| [`project/overview.md`](project/overview.md) | you need the project in one screen: question, mechanism, bet, state |
| [`project/state-of-knowledge.md`](project/state-of-knowledge.md) | you need to know what is established, measured, assumed or open, with the pages that hold the evidence |
| [`project/terminology.md`](project/terminology.md) | you are about to name anything: the canonical project words, one line each, with home pages |
| [`project/notation.md`](project/notation.md) | you write code listings, tensor slices, equations or ratios |
| [`project/rigs.md`](project/rigs.md) | you quote a number: the Pin, the Bench, `[[@key]]`, `ref:` templates |
