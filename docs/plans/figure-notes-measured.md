# Figure notes for Part VIII (slug `measured`): label changes for the figures task

Part VIII reuses the builders of `figures/measured.js` and `figures/range.js` unchanged. The pages reference
them as `::: figure fig-measured-<x> <builder>` (ids: `fig-measured-headline`, `-tensor`, `-square`,
`-ladder-c1`, `-ladder-c2`, `-shuffle`, `-splits`, `-cast`, `-time`, `-reads`, `-stretches`, `-memory`,
`-noise`, `-economics`, `-share-vs-ratio`, `-entropy-ladder`). No new builder is needed. Every UI string
below still uses a retired word (`docs/style/terminology.md` §1, §4.2); the right-hand column is what it
should say. Data keys inside the JSON files (`every_entry_table`, `split`, `track`, …) are not UI text and
may stay. Track names (`s-layer-b4k-r293`) may appear in hover tooltips only next to the scenario line.

Global translation for every builder in both files: entry → cherry; entries' worth → cherries' worth;
entry split → cherry shape; block (data) → punnet; block (positions), block size, "blocks of 4096" →
stretch, stretch length, "stretch 4096"; channel → element (position) or furrow (column); coder →
compressor; read budget / budget → leash; exact model → code-length estimate; model (the LLM) → the LLM or
Qwen3.5-2B; request → sequence; thread → sequence; "layer 3" / "L3" → "KV layer 0 (L3)" the first time in
a figure, then either. Cherry-shape labels: head → `(256,)`, layer → `(2, 256)`, token → `(6, 2, 256)`.
